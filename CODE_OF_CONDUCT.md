# Code of Conduct

## The rule

Be decent to other people here. Disagree about code, formulas, RFC
process, or the correct pronunciation of "nftables" as much as you like.
Don't be cruel, harassing, or exclusionary about it, in this repository
or anywhere else this project's discussions happen.

This is the entire rule. Everything below is elaboration, not addenda.

## What that covers

Harassment, personal attacks, discriminatory language or jokes at
someone's expense (as opposed to the document's own expense, which is
fair game and frankly the whole point), sharing someone's private
information without consent, and sustained disruption of discussion or
review. If you wouldn't want it read back to you in a security
disclosure, don't put it in an issue.

## What this document will not do

Rate you. Section 5.3 is explicit that a host MUST NOT self-assess, and
this project extends the same courtesy to actual people: nobody here is
computing your Evil Rating, and if anyone claims to be, they're doing it
wrong and outside this policy's authority.

## Reporting

Message a maintainer directly, or use GitHub's report tools on the
offending content. Reports are handled privately. You will not be
asked to justify a report publicly, and retaliation against someone
for reporting in good faith is itself a violation of this policy.

## Enforcement

Maintainers may edit, remove, or lock content, and warn, temporarily
restrict, or ban participants, in proportion to what happened. There is
no Evil Rating Authority adjudicating this — a person makes the call,
and can be asked to explain it.

## Scope

Applies to this repository, its issues and pull requests, and any other
space this project uses for discussion. It does not apply to opinions
about RFC 3514, which remain everyone's to hold freely, loudly, and
somewhat besides the point.
